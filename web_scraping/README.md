# Data Collection - Web Scraping

This project is part of the Holberton School curriculum and focuses on learning web scraping with Python.

The exercises cover extracting data from web pages using BeautifulSoup and automating browser interactions with Selenium.

## Learning Objectives

- Understand static and dynamic web pages.
- Parse HTML and use CSS selectors to find elements.
- Extract data using BeautifulSoup.
- Automate browser interactions with Selenium.
- Handle scrolling, pop-ups, and duplicate data.
- Follow good web scraping practices.

## Technologies

- Python 3
- BeautifulSoup
- Selenium
- Requests

## Test Websites
